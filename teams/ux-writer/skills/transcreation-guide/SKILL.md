# 创译(Transcreation)方法论 Skill

**核心信条:翻译的对象不是"字",是"这条文案要在这个界面里让用户做/感受到什么"。**

## 一、翻译前先问四个问题
1. **谁在看**:目标用户是谁、什么文化背景?
2. **在哪看**:控件类型 + 页面位置(按钮 ≠ Toast ≠ 弹窗正文 ≠ 营销 Banner)?
3. **何时看**:触发时机与用户当下的情绪(报错时?抢购失败时?)?
4. **想要什么效果**:引导点击?安抚?强调紧迫?

同一句"已抢光":按钮里 = `Sold Out`(状态标签);弹窗里 = `This item is sold out.`(完整告知)。**控件+场景决定形态。**

## 二、按控件类型的文案形态
| 控件 | 形态 | 示例(英) |
|---|---|---|
| 按钮 / 菜单 | 极简、动宾、Title Case | `Add to Cart` |
| Toast 轻提示 | 短句、结果导向 | `Saved` / `Link copied` |
| 弹窗标题 | 名词短语,点明主题 | `Delete this note?` |
| 弹窗正文 | 完整句,说清后果 | `This can't be undone.` |
| 表单错误 | 出了什么问题 + 怎么办 | `Enter a valid email address.` |
| 营销 Banner | 可大胆创译,允许脱离原文 | (高风险,需人工) |

## 三、地道化 checklist
- 用目标语言用户**真的会说**的表达,而非中式直译。
- 语气匹配品牌(克制/友好/活泼/正式)且尊重当地礼貌层级(如日/韩敬语)。
- 数字、日期、货币、度量单位按当地格式。
- 避免文化不适:手势、颜色、动物、宗教、政治、幽默/双关(双关基本不可直译,需重写)。
- 长度意识:德/法/西通常比英文长,防 UI 截断;CJK 通常更短。

## 四、什么时候必须交人工(标 `需确认`)
- 双关 / 押韵 / 依赖字形的玩法;
- 营销 slogan、品牌口号;
- 法务、支付、隐私、健康等高后果文案;
- 任何你对目标文化把握不足的表达。

> 记住:AI 负责"又快又稳的初稿 + 诚实的风险标记",母语审校负责"最后一公里"。
